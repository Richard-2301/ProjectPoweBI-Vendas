
# 📊 Projeto Power BI - Análise de Vendas

Este projeto tem como objetivo apresentar um painel interativo desenvolvido no **Power BI Desktop**, com foco na análise de desempenho comercial e controle de produtos.

## 🧾 Descrição

O painel foi criado a partir de três arquivos:
- **BaseVendasCompleta.xlsx**: contém os dados transacionais de vendas.
- **CadastroProdutos.xlsx**: contém informações sobre os produtos cadastrados.

## 📈 Principais Métricas do Dashboard

- Faturamento total por período
- Volume de vendas por produto
- Comparativo de desempenho por categoria
- Ranking de produtos mais vendidos
- Análise de ticket médio
- Evolução mensal das vendas

## 🛠️ Ferramentas utilizadas

- **Power BI**
- **Excel** (para tratamento e organização dos dados)
- **DAX** (linguagem para criação de medidas e KPIs)

## 💡 Objetivos do Projeto

- Visualizar de forma clara o desempenho de vendas da empresa
- Facilitar a tomada de decisão com indicadores visuais
- Identificar os produtos com maior e menor saída
- Auxiliar no controle de estoque e planejamento de vendas
